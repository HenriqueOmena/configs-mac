# ⚡ Cheatsheet - Novos Atalhos

## 🪟 Navegação de Janelas (Splits)
| Atalho | Ação |
|--------|------|
| `<C-h>` | ← Janela esquerda |
| `<C-j>` | ↓ Janela abaixo |
| `<C-k>` | ↑ Janela acima |
| `<C-l>` | → Janela direita |
| `<C-Up>` | ⬆️ Aumenta altura |
| `<C-Down>` | ⬇️ Diminui altura |
| `<C-Left>` | ⬅️ Diminui largura |
| `<C-Right>` | ➡️ Aumenta largura |

## 📋 Buffers
| Atalho | Ação |
|--------|------|
| `<S-h>` | Buffer anterior |
| `<S-l>` | Próximo buffer |
| `<leader>bd` | Fecha buffer atual |
| `<leader>ba` | Fecha todos exceto atual |

## 🖥️ Terminal
| Atalho | Ação |
|--------|------|
| `<C-\>` | Abre/fecha terminal |
| `<C-x>` (no terminal) | Volta ao modo normal |
| `<leader>tt` | Toggle terminal (alternativo) |

## ✂️ Edição Visual
| Atalho | Ação |
|--------|------|
| `<` (visual) | Indenta ← e mantém seleção |
| `>` (visual) | Indenta → e mantém seleção |
| `J` (visual) | Move linhas ↓ |
| `K` (visual) | Move linhas ↑ |

## 🔍 Busca e Navegação
| Atalho | Ação |
|--------|------|
| `n` | Próximo resultado (centralizado) |
| `N` | Resultado anterior (centralizado) |
| `<C-d>` | Scroll down (centralizado) |
| `<C-u>` | Scroll up (centralizado) |
| `<Esc>` | Limpa highlight da busca |

## 💾 Salvar/Sair
| Atalho | Ação |
|--------|------|
| `<leader>w` | Salva arquivo |
| `<leader>q` | Fecha janela |

## 🌳 Nvim-Tree (File Explorer)
| Atalho | Ação |
|--------|------|
| `<C-n>` | Abre/fecha nvim-tree |
| `h` | Fecha pasta (ou vai para pai) |
| `l` | Abre pasta/arquivo |
| `v` | Abre em split vertical |
| `s` | Abre em split horizontal |
| `a` | Criar arquivo/pasta |
| `d` | Deletar |
| `r` | Renomear |
| `y` / `Y` / `gy` | Copiar nome/path relativo/absoluto |
| `H` | Mostra/esconde arquivos ocultos |
| `?` | Ajuda completa |

## ✨ Features Automáticas
- **Highlight on yank:** Texto copiado pisca (feedback visual)
- **Format on save:** Código formata automaticamente ao salvar
- **Splits inteligentes:** Sempre abre à direita/abaixo
- **Ícones no tree:** Arquivos, pastas e status do git
- **Largura adaptativa:** Mostra nomes completos automaticamente
